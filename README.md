# s3vdrm - WIP

## Overview

The project's goal is making old S3 graphics cards still useable under modern linux. `s3vdrm` is going to be a DRM/KMS driver focused on supporting as many card's features as possible. 

## Current state

The driver is in very early stage of developement and is currently not functional.

## Supported hardware

Support would be mainly focused on S3 Virge and Virge DX cards, as they are well documented, simmilar, and very popular. S3 Virge GX could also work. More cards will propably be supported in the future.

## Goals

 - automatic card specs detection
 - mode setting support
 - vga i2c communication support
 - memory overclocking support
 - hardware cursor support
 - multistream display support (through STREAMS processor)
 - 2d accelerator support
 - 3d accelerator support (under evaluation)
